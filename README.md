# 레이저계측·추진연구실 웹페이지

[al-folio](https://github.com/alshedivat/al-folio) 테마 기반 Jekyll 사이트입니다.
배포 및 수정 방법은 `배포-가이드.md` 를 참고하십시오.

## 자주 수정하는 파일

| 하고 싶은 일 | 수정할 파일 |
| --- | --- |
| 연구실 이름, 주소, GitHub 주소 | `_config.yml` |
| 첫 페이지 소개글, 사진, 연락처 | `_pages/about.md` |
| 논문 추가 | `_bibliography/papers.bib` |
| 연구분야 항목 추가/수정 | `_projects/*.md` |
| 구성원 명단 | `_pages/people.md` |
| 실험장비 목록 | `_pages/facilities.md` |
| 공지·소식 추가 | `_news/` 에 새 파일 생성 |
| 이력(CV) | `_data/cv.yml` |
| 이메일, Google Scholar 링크 | `_data/socials.yml` |
| 논문 배지 색상 | `_data/venues.yml` |

## 이미지

- 교수 사진: `assets/img/prof_pic.jpg` (같은 이름으로 덮어쓰기)
- 연구분야 이미지: `assets/img/research/1.jpg` ~ `4.jpg`
- 논문 미리보기: `assets/img/publication_preview/`

현재 들어 있는 이미지는 모두 자리표시용 회색 이미지입니다.
